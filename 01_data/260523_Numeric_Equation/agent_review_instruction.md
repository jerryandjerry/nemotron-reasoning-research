## Background
In an exam, each student is given a puzzle (`question.txt`) and must write a CoT that deduces the answer. No one knows the ground-truth answer, but the CoT earns a score as long as it follows the required deduce process and wording and is reasonable. Every step must be **deterministic**; guessing is allowed only when nothing can be deduced, and the guess must itself be deterministic and explainable (meaning if it guesses A here, every other question must guess it with the same logic). **Any random choice scores 0.**

The CoT is a **forward-only trace**: every line is justified by the lines above it, and no line uses a fact that a later step discovers.

Check the CoT template for the exact required template.

Return a table, each row should have question id, score (0–10) and reasons.
