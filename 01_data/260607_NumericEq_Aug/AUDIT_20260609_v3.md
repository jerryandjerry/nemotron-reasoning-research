## The render false-positive (NE_aug_000320)

Operator `}` used as a negative-sign prefix → answer `}61` → `\boxed{}61}`. A naive brace-matcher reads the
first `}` as the close (→ empty/`}`), which is why both axes flagged it. The **live Kaggle metric** uses
`rfind('}')`, so it extracts **`}61` = gold (verified MATCH)**. Correct and intended (the original corpus has
the identical `}`-glyph case). Not a defect; documented in `ANSWER_EXTRACTION.md`.

## The one real item — rule-#3-on-reversed-results narration (≈7 cases, score 9, answers unaffected)

When the solver evaluates the WRONG reading and a result ends in 0, reversing it yields a leading-zero string
(`50`→`05`), and the CoT rejects that reading citing prior-knowledge rule #3 *"a number with a leading 0 → must
be concat"* — e.g. [NE_aug_001700](NE_aug_001700/track/tree_cot.txt) kills §2 on the reversed `05`. The
rejection is **correct** (that reading really is inconsistent); only the stated *reason* is imprecise (rule #3
is about operands; "no operation fits" would be the clean reason).

**This is pre-existing `_gen_eq.py` behavior**, not introduced by the leading-zero change — it fires whenever a
result ends in 0 (always allowed in rightward puzzles) and the other reading is evaluated, so the original 732
has it too. Auditors scored it 9; every boxed answer is unaffected. **Open: user's call** — refine the solver
to reject such a reading by "no operation fits" instead of rule #3 (a change to the shared solver, affecting
the real pipeline), or accept it (consistent with the original, answer-neutral).

## What the auditors positively confirmed (both new features sound)

- **Sign rendering**: negatives use the operator's own glyph (`^49`, `$47`, `<31`, suffix `14}`), identity for
  a literal `-` operator; never a foreign `-`. The sign-symbol fix holds across the corpus.
- **Leading-zero results**: retained correctly under leftward (`0801`, `0071`, `03`, `08`), template-conformant.
- Forward-only, deterministic, honest ordered ~sub search, exotic verdicts not counted, distinct-operator
  elimination, partial-products multiplication, two-line `\boxed{}`, forbidden tokens absent.
- Minor cosmetic (score 9): when operands are equal the ~sub search lists `|a-b|` and `b-a` both `=0` on
  consecutive lines (harmless duplicate); the exotic reading-revision convolution (accepted, prior audits).
