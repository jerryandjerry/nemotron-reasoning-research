## Format sub-10 triage (187 total) — ALL trace to a stale template, none are data defects
Every format flag is one of:
- "spec phrase *First, let me assign letters to each symbol* replaced by BPE-split + read-symbol prose"
- "concat/arith lock has no `concat_rev =` / VARIANT label" (template expects labels; generator emits formulas `b∥a`, `a+b+2`)
- empty `\boxed{}` on the instruction line; U+2212 minus in interval lines

**Root cause:** `cot_template.md` predates this session's generator changes (the BPE merge-split table and the
formula-notation locks). The aug CoTs are produced by the **identical `_gen_crypt.gen_cot`** as the corpus
training CoTs, so they are **byte-identical in format to the already-audited corpus** — proven by direct
comparison (`003066` aug vs a corpus `mixed_concat_little_endian` original use the same `so lock g = b∥a` /
`applying h(a,b) = a+b+2` wording). The fix is a **doc update to `cot_template.md`**, not a data change.

## Verdict
The augmentation is **as sound as the corpus** — same generator, forward-only search, every box clean and
GT-matching. No real reasoning or format defect. The only genuine quality tier is the **~21 under-determined
("ambiguous") puzzles** whose answer rides on a deterministic tie-break; this is an allowed soft pattern that
also exists in the corpus.
